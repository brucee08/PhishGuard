PhishGuard Dashboard

Overview of the PhishGuard URL security detection system.

System Status

PhishGuard uses a machine learning model to classify URLs as potentially phishing or legitimate.

The trained model is based on URL characteristics extracted from the submitted website address.

Detection Features

  • URL Length
  • HTTPS Usage
  • Number of Dots
  • Number of Hyphens
  • Number of Slashes
  • Number of Digits
  • Special Characters
  • Number of Subdomains

Machine Learning Model

Model: Random Forest Classifier

Classes: Legitimate and Phishing
