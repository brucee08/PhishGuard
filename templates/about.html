About PhishGuard

PhishGuard is a machine learning based URL security analysis system designed to identify potentially phishing URLs.

How PhishGuard Works

When a user submits a URL, PhishGuard extracts important characteristics from the URL.

These characteristics are passed to a trained Random Forest machine learning model, which classifies the URL as potentially legitimate or phishing.

A separate risk engine analyzes the URL characteristics and machine learning prediction to produce a risk score.

Technologies Used

  • Python
  • Flask
  • Scikit-learn
  • Pandas
  • Joblib
  • HTML
  • CSS
  • JavaScript

Purpose

The project demonstrates how machine learning and URL-based feature analysis can be combined to assist in identifying potentially malicious web addresses.

PhishGuard is intended as an educational security analysis project and should not be treated as a guarantee that a website is safe or malicious.
